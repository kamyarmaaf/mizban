# راهنمای راه‌اندازی احراز هویت

## مراحل راه‌اندازی

### 1. تنظیم فایل .env

فایل `.env` را در ریشه پروژه ایجاد کنید و اطلاعات Supabase خود را اضافه کنید:

```bash
VITE_SUPABASE_URL=your_supabase_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

### 2. ساختار دیتابیس

دیتابیس به صورت خودکار با استفاده از migrations راه‌اندازی شده است و شامل:

- جدول `user_profiles`: اطلاعات کامل کاربران
  - نام کامل
  - شماره تلفن (unique)
  - ایمیل (unique)
  - نقش (admin, provider, tourist)
  - استان و شهر (برای میزبان‌ها)
  - نوع میزبانی (برای میزبان‌ها)

### 3. انواع کاربران

سیستم سه نوع کاربر دارد:

1. **بازدیدکننده (Tourist)**
   - دسترسی به رزرو تجربه‌ها
   - مشاهده داشبورد شخصی

2. **میزبان (Provider)**
   - ایجاد و مدیریت تجربه‌ها
   - مشاهده رزروها و مهمان‌ها
   - داشبورد میزبان

3. **ادمین (Admin)**
   - دسترسی کامل به سیستم
   - مدیریت کاربران و تجربه‌ها

### 4. نحوه استفاده

#### ثبت نام

کاربران می‌توانند با اطلاعات زیر ثبت نام کنند:

- **برای همه کاربران:**
  - نام و نام خانوادگی
  - شماره موبایل
  - ایمیل
  - رمز عبور

- **فقط برای میزبان‌ها:**
  - استان اقامت
  - شهر اقامت
  - نوع میزبانی

#### ورود

کاربران با شماره تلفن و رمز عبور خود وارد می‌شوند.

### 5. امنیت

- همه جداول دارای Row Level Security (RLS) هستند
- کاربران فقط به داده‌های خود دسترسی دارند
- رمز عبور با استفاده از Supabase Auth به صورت امن ذخیره می‌شود

### 6. توجه

این یک MVP است و برخی قابلیت‌ها در نسخه‌های بعدی اضافه خواهند شد:
- بازیابی رمز عبور
- تایید ایمیل
- ویرایش پروفایل
- احراز هویت دو مرحله‌ای
